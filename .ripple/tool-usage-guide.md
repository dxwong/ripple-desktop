# AI 工具使用规范
> 通用 AI 操作守则，适用于所有 Ripple 项目。
> 每次会话开始时，AI 应阅读此文件并遵守以下规范。

## 文件修改
- **大文件（>100行）**：AI 只给出 **文件路径 + 行号 + 修改内容**，不直接写入
- **小文件（<100行）**：可用 `write_file` 全量写入，但必须先 `read_file` 确认内容
- **任何时候**：修改前先 `read_file` 确认当前内容，改完后验证结果

## Shell 操作
- **单行修改**：优先用 `sed` + 行号（`sed -i 'N s/old/new/'`）
- **避免**：用 `node -e` 做多行字符串匹配替换（中文/空格差异易失败）
- **验证**：每次 shell 操作后必须检查结果（读文件 / 查行数）

## 风险红线
- ❌ 不要用 `write_file` 覆盖大文件（>100行）
- ❌ 不要用多行模糊匹配做字符串替换
- ❌ 修改核心服务文件前先通知用户
- ✅ 不确定时，只给出修改方案让用户决定
